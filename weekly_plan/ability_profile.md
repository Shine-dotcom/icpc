# 算法能力画像（2026/8 评估）

> 数据来源：全仓 396 个 `.cpp`（CF ~120、牛客 ~80、区域赛 ~100、洛谷 ~40、杂项 ~50）
> 维护时长约 11 个月（自 2025/9），约 1.1 题/天
> 注：补题占比高，CF 分数失真，故按分层定位

## ① 稳定带（赛中能稳定 AC）—— 保底分
- Div2 A/B 全类型：贪心/构造/模拟/位运算/基础数论
- 占全仓 70%+ 题量，已够用，不再投入时间

## ② 可及带（补题/给足时间能 AC）—— 真实库存
- 数据结构：线段树全家桶（P3373 加乘双lazy、P1253 赋值+加+max、P4513 最大子段、P1438 等差区间加、P1471 方差、P1558 位掩码）+ 带修莫队 P1903 + 双BIT P1637
- 数论：exgcd、CRT、原根 P6091、线性筛
- DP：背包全家桶（分组/多重/二进制拆分/单调队列 P1776）+ 4D DP P1541 + 树背包 P1273 + 2D 子集 DP P1284
- 图：Dijkstra、DSU、拓扑、二分图染色
- 约等于 Div2 C~D / 区域赛银牌中档题

## ③ 极限带（补题也吃力、多数卡住）—— 当前天花板

- 大型暴力枚举（2025shenyang/m 8!、icpc_nc1/j 323 行扑克牌）—— 能硬肝但代码失控

## 风格与风险
- 代码风格统一、有对拍/对照复盘习惯（_cor、test.py、right/wrong.txt）
- 风险1：一次写对能力不足（cf1051/c 读入完空着、逗号笔误、acwing860 潜在 bug）
